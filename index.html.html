Feature Functions & Speaking Practice Fungsi Fitur & Latihan Speaking
1. Power Indicator Light 1. Lampu Indikator Daya
Function: It shows whether the device is receiving electrical power and turned on. Fungsi: Menunjukkan apakah perangkat menerima daya listrik dan menyala.
2. Internet Port (WAN) 2. Port Internet (WAN)
Function: Connects the router to the modem or ISP cable to receive global internet connection. Fungsi: Menghubungkan router ke modem atau kabel ISP untuk menerima koneksi internet.
3. LAN Ports (Local Area Network) 3. Port LAN (Jaringan Area Lokal)
Function: Provides wired Ethernet network connections to computers, laptops, or smart devices. Fungsi: Menyediakan koneksi jaringan kabel Ethernet ke komputer, laptop, atau perangkat pintar.
4. WLAN Antenna (Wireless Local Area Network) 4. Antena WLAN
Function: Transmits and receives wireless Wi-Fi signals to connected mobile devices. Fungsi: Memancarkan dan menerima sinyal Wi-Fi nirkabel ke perangkat seluler.
5. WPS Button (Wi-Fi Protected Setup) 5. Tombol WPS
Function: Allows quick and secure wireless connection between devices without entering a password. Fungsi: Memungkinkan koneksi nirkabel cepat tanpa perlu memasukkan kata sandi.
6. Reset Button 6. Tombol Reset
Function: Restores the router configurations and passwords back to default factory settings. Fungsi: Mengembalikan konfigurasi dan kata sandi router kembali ke pengaturan awal pabrik.

Reading & Quiz Section Reading Text & Kuis
A Wi-Fi router is a hardware device that routes data packets between computer networks. It plays a critical role in home and office networking. Modern routers feature multiple ports such as WAN for internet cable connection, LAN ports for local wired devices, and wireless antennas (WLAN) to broadcast Wi-Fi signals. Indicators like power lights notify users of operating status, while WPS buttons provide easy wireless pairing. If configuration errors happen, the reset button restores default factory settings. Router Wi-Fi adalah perangkat keras yang mengarahkan paket data antar jaringan komputer. Router memainkan peran penting dalam jaringan rumah dan kantor. Router modern memiliki beberapa port seperti WAN untuk koneksi kabel internet, port LAN untuk perangkat kabel lokal, dan antena nirkabel (WLAN) untuk memancarkan sinyal Wi-Fi. Indikator seperti lampu daya memberi tahu pengguna tentang status pengoperasian, sementara tombol WPS memberikan kemudahan penyambungan nirkabel. Jika terjadi kesalahan konfigurasi, tombol reset mengembalikan pengaturan awal pabrik.
